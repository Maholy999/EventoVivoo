Introducción

EventoVivo aplica integración continua para validar una plataforma de eventos universitarios antes de fusionar cambios. El repositorio incluye estrategia de ramas, documentación de ejecución, pruebas unitarias e integración, migraciones PostgreSQL y un entorno local reproducible con Docker Compose.

Historia relacionada: R2 - Detectar traslapes entre sesiones sin confundir los horarios consecutivos.

Criterio de aceptación: si una sesión termina exactamente cuando comienza otra, no existe choque; los solapamientos parciales, totales e idénticos sí deben detectarse.

Prueba: src/domain/__tests__/schedule.test.ts, casos “sesiones consecutivas” y hasScheduleConflict.

Caso de error

Introducir dos sesiones contiguas (12:00-14:00 y 14:00-16:00) debe producir schedule_conflict=false. Si la prueba falla, revertir con git revert <commit-inestable> o regresar a la etiqueta estable correspondiente.

Registros y secretos

Los registros se obtienen con docker compose logs app. No se colocan contraseñas ni tokens en capturas; CI usa secretos/variables del entorno y el Docker Compose local usa únicamente valores de prueba documentados.
